# Security Policy

## Reporting

Please do not publish unpatched security issues in public issues. Use the repository's private security reporting channel when available.

## Scope

Relevant reports include extension permission abuse, unintended page access, data exfiltration, unsafe download initiation, and script injection within the extension UI.

## Design goals

- no remote executable code
- no eval or dynamic code generation
- user-initiated scanning
- user-initiated downloads
- local-first processing
- minimal install-time permissions
