# Release Channels

## Developer

Purpose: maintainers and contributors.

Includes:
- full source
- tests
- diagnostics
- release validation
- architecture and policy docs
- GitHub workflow assets

## Personal

Purpose: daily use by the maintainer.

Includes:
- same scanning engine
- diagnostics enabled
- personal build marker
- no developer telemetry

No account or cloud service is required.

## Public

Purpose: GitHub public repository and Chrome Web Store.

Includes:
- clean UI
- diagnostics off by default
- public README/privacy/store listing
- store-ready extension package
